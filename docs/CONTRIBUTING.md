# Guía de Contribución a GeoRhythm

## Convención de Ramas (Git Flow)
- `main`: Código estable y versiones publicables con etiquetas (`vX.Y.Z`).
- `develop`: Rama de integración activa.
- `feature/*`: Nuevas características.
- `refactor/*`: Mejoras de diseño sin cambio funcional.
- `test/*`: Cobertura de pruebas unitarias.
- `docs/*`: Documentación del proyecto.

## Estándar de Commits
Se sigue estrictamente la especificación [Conventional Commits](https://www.conventionalcommits.org/):
- `feat(scope): ...`
- `fix(scope): ...`
- `refactor(scope): ...`
- `test(scope): ...`
- `chore(scope): ...`
